# dev-boost

Fast project scaffolding and code generation CLI for developers

## Features

- **Project Scaffolding**: Quickly generate projects from templates (FastAPI, Flask, React, Vue)
- **Snippet Management**: Store and reuse code snippets
- **Code Generation**: Generate CRUD, API, models, and components without paid APIs

## Supported Templates

- `fastapi` - FastAPI REST API
- `flask` - Flask web application
- `react` - React frontend
- `vue` - Vue.js frontend

## Supported Code Types

- `crud` - CRUD operations class
- `api` - API router with endpoints
- `model` - Pydantic data model
- `component` - React component
